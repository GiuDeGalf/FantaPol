# Contribuire a FantaPol

Issue e pull request sono benvenute.

1. Crea un fork del repository.
2. Apri un branch dedicato.
3. Mantieni il progetto senza dipendenze obbligatorie lato browser.
4. Esegui `npm test` oppure `node tests/engine.test.js`.
5. Descrivi nella pull request il comportamento precedente e quello nuovo.

Non includere listoni, backup, rose, credenziali o altri dati personali nei commit.
